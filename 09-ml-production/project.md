# Design an application that uses a trained model

Choose a classification or regression project you already understand. Draw its
input, preparation, fitted model, output and application action as distinct steps.

Record the feature names, feature order, accepted units and required input checks.
Explain what is preserved from training and what runs for each prediction.

Choose when results are computed and where inference runs. Explain these choices
using the application's needs: immediate input, periodic records, local operation,
available compute and network access.

Specify one check for service operation and one check for prediction quality.
State where reliable outcome labels could come from and what you would do if they
are delayed. Describe how a reviewed replacement model would be released and how
you could restore the previous version.

The deliverable is an annotated design and a short explanation. Publishing a
service is outside this exercise.
