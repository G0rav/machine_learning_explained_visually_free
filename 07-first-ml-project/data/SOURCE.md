# Dataset source

This lesson uses `penguins.csv` from the [Palmer Penguins project](https://github.com/allisonhorst/palmerpenguins), downloaded from `inst/extdata/penguins.csv`. The project publishes the dataset under [CC0 1.0](https://github.com/allisonhorst/palmerpenguins/blob/master/LICENSE.md).

- Original data: Palmer Station LTER and Gorman et al. (2014), as credited by the Palmer Penguins project.
- These are penguins sampled around the Palmer Archipelago in 2007–2009. A high test score on this dataset does not establish performance on other populations or new field conditions.
